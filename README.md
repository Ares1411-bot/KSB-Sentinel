# Sentinel PLC 交互原型

当前版本：v22（2026-10-13），修正采集组间隔单位为 ms。

## v21 已确认变更

- 新增设备第二步按采集组展示页签，支持新增及编辑组名、采集间隔（ms）。
- 删除点位先置灰，保存前可恢复；保存设备时排除待删除点位。组与点位调整不会改动原模板。
- 模板支持新增、编辑、启用/停用，开放设备信息、组及所有点位业务字段。
- 模板新增/编辑和新增设备第二步均提供“动态字段配置”，默认收起、点击展开；折叠保留填写值。
- 设备协议参数从模板带入，在设备中修改只影响当前设备。
- 切换协议保留各协议已填写配置；本版 S7、Modbus TCP、Modbus RTU 动态字段均为表单示例，实际字段需由协议定义提供。
- 回归检查覆盖分组、新增组、间隔、点位删除/恢复、保存排除、模板编辑/新增及协议参数独立保存。

## 前端数据接入补充

- 采集组使用 `groups: [{ name, intervalMs }]`，`intervalMs` 单位为 ms，默认 1000 ms，须为正整数。
- 点位通过 `templateGroup` 关联采集组；编辑草稿的 `deleted` 标识用于置灰与恢复，保存时过滤并去除此标识。
- 模板与设备的协议参数使用 `protocolConfig`；模板的 `protocolConfigCache` 用于保留不同协议的编辑值。
- 动态表单由 `protocolSchemas` 驱动，支持数值/文本输入、单选和下拉。接入时替换示例 schema，并增加协议对应的实际校验。
- 折叠区使用原生 `details/summary`；模板与设备采用独立草稿及单选组名称，避免互相影响。

## v19 已确认变更

- “平台默认规则 / 自定义规则”两个页签；按项目 → 厂房 → 机组 → 设备选择自定义范围。
- 自定义规则按设备独立保存；未配置自定义的数值字段沿用平台默认规则。停用自定义规则不会回退为默认规则。
- 同一字段所有等级共用一种数值条件：超出正常范围、高于上限或低于下限。
- 布尔异常值只允许在设备自定义中配置，使用当前设备 PLC 返回值枚举下拉。
- 修复新增等级无响应，支持最多四个不同等级。
- 移除持续时间配置与相关提示。
- 增补启动检查，覆盖新增等级、共享条件、默认继承及跨设备/项目隔离。

PLC 枚举目前为点位 `returnedValues` 演示元数据；接入后由采集接口提供，不在配置控件中写死。

## 运行

直接打开 `dist/index.html`，或在仓库根目录启动静态服务器：

```bash
python -m http.server 8000 --directory dist
```

然后访问 http://localhost:8000 。无需安装依赖或编译。

## 功能

- PLC 设备、模板、标准字段及平台默认/设备自定义预警规则配置。
- 项目 → 厂房 → 机组 → 设备四级筛选。
- 汇总 PLC 数据卡片、参数趋势、设备标签悬停展开。
- 多等级预警与颜色配置；布尔异常值自定义。
- 设备与标准字段两个预警记录入口、事件过程及处理表单。
- 首次触发、等级升降、数值变化、恢复、再次异常、处理结束节点。
- 字段记录时间筛选、等级/时间/时长排序、未处理数量提示。
- 独立事件趋势窗口及所有趋势的放大查看弹窗。

## 检查

安装 Node.js 后，在仓库根目录执行：

```bash
node tests/startup-smoke.cjs
node --check dist/assets/alert-records.js
node --check dist/assets/expanded-trends.js
```

启动检查使用简化 DOM，不能替代真实浏览器的布局与交互验收。

## 前端接入说明

这是可运行的交互原型，尚未接入服务端。设备、点位、趋势、历史事件及处理人员使用演示数据；配置、处理记录和附件随刷新清空。附件仅通过本地对象 URL 预览；AI 建议为规划功能展示。

`window.sentinelPrototype` 提供设备、字段、规则、趋势及刷新接口；`window.PLCRecords` 提供事件列表、详情和未处理数量；`window.PLCExpandedTrends` 提供放大趋势开关。接入时将演示数据替换为实际 API，事件创建、升级记录及处理结束由服务端保存。

处理完成即结束当前事件；本版已移除“处理后仍异常”自动生成新事件的演示逻辑。
