# Sentinel 设备健康 Web 交互原型

同一仓库内提供两个独立入口，共用设计规范与演示事件数据约定。

页面已应用 Sentinel 统一设计规范：几何业务背景、思源黑体字族、主蓝 `#0D6BB0`、次级蓝 `#298ED6/#467DEB`、20px 内容边距及规范化卡片与按钮层级。

## 当前交互

- `dist/plc/index.html`：PLC 展示、设备管理、模板、标准字段、预警配置。
- `dist/alerts/index.html`：预警统计、查询、分类、离线监控、处理闭环。
- PLC 卡片“预警记录”打开当前设备的 PLC 专属记录弹窗；趋势统计入口打开当前标准字段的 PLC 记录侧卡。详情、处理、事件趋势和放大均在 PLC 页面完成。
- 顶部预警中心入口独立跳转到平台中心，两边共用 PLC 事件及处理结果。
- 设备展开卡片只读展示点位、标准字段、当前值、地址、精度、系数及偏移量。“编辑设备”回填当前接入、分组与点位配置，直接保存修改；取消不改动设备，保存保留原设备和点位 ID，删除点位时清理其卡片引用。

## 文件结构

- `src/shared/`：共用页面外壳、设计样式、项目层级、导航和会话存储。
- `src/plc/`：页面结构、样式、演示数据分离；`modules/` 按功能拆分逻辑，顺序由 `modules.json` 指定。
- `src/alerts/`：独立页面、样式、演示数据与逻辑；`runtime.js` 读取 PLC 快照，不加载 PLC 配置逻辑。
- `dist/`：构建产物；`dist/assets/` 保留图片素材。

编辑 `src/` 后运行 `node scripts/build-prototypes.cjs` 生成部署目录，无需安装依赖。PLC 逻辑片段编译成单个闭包，以保留原有作用域。根入口默认进入 PLC，`?view=alerts` 进入中心。

通过静态服务器预览两个页面。同一来源、同一标签页通过 `sessionStorage` 保存演示配置、事件与处理结果；关闭标签页后失效。`file://` 模式不保证跨页面存储。事件快照不是实时接口，照片与附件的本地临时地址在刷新或跨页后不保证可用。

运行 `node tests/alerts-smoke.cjs`，覆盖 PLC 配置与展示、中心分类与处理、独立加载、筛选跳转、事件回传、配置保留和重载防重。使用模拟 DOM 检查，不替代浏览器视觉核验。
